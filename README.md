# One-with-Death-TranslatePatch

《One with Death》（死亡化身）模组的简体中文汉化补丁，作者：Hjx。

死亡化身，成为死灵法师吧！掌控亡魂、号令亡灵大军，踏上你的亡灵之道。

## 功能
- 完整汉化模组文本（DefInjected + Keyed）
- 支持 RimWorld 1.5 与 1.6
- 附带 1.6 版 Harmony 补丁（`Hjx_Necromancy_Harmony`），修复/替代部分原版逻辑

## 前置要求
- 需安装原版模组《One with Death》（[Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3448902635)）

## 安装
1. 将本仓库文件夹放入 `RimWorld/Mods` 目录
2. 在游戏内启用模组，并确保加载顺序位于《One with Death》之后

## 目录结构
- `1.5/`、`1.6/`：对应游戏版本的汉化文件
- `Source/`：1.6 Harmony 补丁源码
- `About/`：模组元数据与预览图
